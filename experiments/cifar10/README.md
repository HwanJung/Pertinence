# CIFAR-10 experiment

This directory contains the complete CIFAR-10 reproduction bundle.

- `configs/`: runnable experiment and asset manifests
- `data/`: the model-zoo catalog and compact final solution table
- `docs/`: protocol, runbook, Pareto analysis, and completed results
- `figures/`: catalog and final experiment figures
- `scripts/`: CIFAR-10-specific catalog and final-result analysis

Runtime files are isolated under `artifacts/cifar10/`. Start with
[`docs/runbook.ko.md`](docs/runbook.ko.md) when reproducing the run.
